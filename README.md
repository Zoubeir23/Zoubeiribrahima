# Zoubeir Ibrahima — Portfolio

Portfolio personnel de Zoubeir Ibrahima, développeur fullstack.

## Stack

- Vite + TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Développement local

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

## Déploiement

Déployé sur Vercel. Chaque push sur `main` déclenche un déploiement automatique.
